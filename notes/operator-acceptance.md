# Operator acceptance

Status: preparation for review. No observational result is claimed.

The operator table intentionally has no invented names. Each row needs a primary person, backup, a confirmation of their own archive access and a linked DR3 dry-run log. Nobody is assigned by this change.

The lead confirms the small-query-first release order in RUNBOOK.md, verifies the current outage and release schedule on ESA's news page, and records a decision before the outage. Account-wide concurrency includes every process run by that person.

A row is ready only when both operators have independently confirmed access and at least one has supplied the row's dry-run evidence. A missing confirmation blocks that job. The release-day status post and hand-over to other repositories still require a human signature.
